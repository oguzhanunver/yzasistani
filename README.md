# YZ Asistanı Android

Bu proje `https://sohbet.yzasistani.tr` sohbet uygulamasını Android uygulamasına bağlar.

## GitHub Actions ile APK

1. Bu klasörü GitHub deposuna yükleyin.
2. **Actions > Build Android APK > Run workflow** seçin.
3. İşlem bitince **Artifacts** bölümünden `yz-asistani-debug-apk` dosyasını indirin.
4. ZIP içindeki APK'yı telefona kurun.

İlk sürümde web sitesindeki üyelik, sohbet, dosya yükleme ve profil ekranları kullanılmaya devam eder. Uygulama için ayrıca API anahtarı gerekmez.
